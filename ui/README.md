# 馬路三寶檢舉輔助系統：使用者介面

這個介面在本機跑一個網頁，把情境圖的流程從頭到尾走一遍：

**上傳影片＋GPS → AI 分析（即時畫面＋進度）→ 違規審查 → 檢舉單確認 → 送出（autoForm 自動填表，或模擬）**

分析有兩種方式，在上傳頁的「分析方式」切換：

| 方式 | 說明 | 需要 |
|---|---|---|
| **真實模型** | 透過推論服務（`../inference_service`）跑組員的 `run_pipeline.py`：車輛、車牌、號誌、標線模型與違規規則 | 先執行專題資料夾的 `下載模型.cmd`、`安裝環境.cmd`，再開 `啟動推論服務.cmd` |
| **模擬展示** | 影片真的會被讀取、抽幀、畫框、剪片，但偵測結果是假資料；不需要 GPU | 什麼都不用 |

> 自動填表透過推論服務執行組員的 autoForm，預設是**測試模式（只填不送）**。也可以切到「模擬送出」，完全不連警察局網站。

## 啟動

只需要 Python 3.8 以上和 `opencv-python`（perception 的環境本來就有）。

- 要用真實模型：先雙擊專題資料夾的 **`啟動推論服務.cmd`**（視窗保持開著）
- 雙擊 **`啟動介面.cmd`**，瀏覽器會自動打開 http://127.0.0.1:8765
- 要用手機展示：雙擊 **`手機展示模式.cmd`**，手機連同一個 Wi-Fi，打開視窗裡顯示的網址
  （第一次執行如果跳出 Windows 防火牆，請按「允許存取」）

用指令啟動也可以：

```powershell
cd ui
python server.py            # 只有本機能連
python server.py --lan      # 開放區網，讓手機連
```

裝了 ffmpeg 的話，剪輯片段會轉成 H.264，保證瀏覽器能播放。沒裝的話，片段播不了時會自動改播原影片的那一段。

推論服務的網址預設是 `http://127.0.0.1:8770`。要改（例如搬上雲端），複製 `config.example.json` 成 `config.json` 後修改：

```json
{ "inference_url": "https://你的雲端主機:8770", "inference_api_key": "推論服務設定的密鑰" }
```

## 介面功能

| 頁面 | 內容 |
|---|---|
| 1 上傳影片 | 拖曳上傳影片；GPS 可選常用地點、輸入座標、點地圖，或上傳 GPS 檔（CSV / GPX / NMEA，範例：`samples/sample_track.csv`）；可設定錄影開始時間 |
| 1 分析方式 | 真實模型／模擬展示；顯示推論服務是否連線、GPU、模型檔是否齊全；可選「只分析前 N 秒」 |
| 2 AI 分析 | 處理階段進度、即時畫面（真實模型會畫出偵測框）、FPS 與剩餘時間、即時違規、系統紀錄、取消分析 |
| 3 違規審查 | 違規卡片（確定／疑似、判定條件 x/y 或信心值、車牌、時間、地點）、可點的時間軸、播放違規片段與判定依據、忽略或建立檢舉單 |
| 4 檢舉單確認 | AI 預填的欄位都可以修改；依 GPS 推薦受理縣市；附佐證影片和檢舉人資料 |
| 5 送出 | **自動填表**：推論服務開瀏覽器執行 autoForm，顯示填表進度、等待驗證、可取消；預設測試模式只填不送，正式送出要再勾選確認。**模擬送出**：展示用的填表動畫與驗證碼。可下載案件 ZIP |
| 案件紀錄 | 進行中的檢舉（可繼續或刪除）和所有已產生的案件 |
| 檢舉人資料 | 姓名、身分證、電話等，每個帳號各自一份 |

## 登入

打開介面會先看到登入畫面，可以用 Email＋密碼註冊／登入，也可以按「使用 Google 帳號繼續」（**模擬**，不會連到 Google，選示範帳號或輸入任一個 Gmail 就能登入）。

- 帳號存在 `ui/data/accounts.json`，密碼用 PBKDF2 加鹽雜湊，不存明碼。
- 勾「記住我」，關掉瀏覽器再開仍是登入狀態；不勾的話，關掉分頁就要重新登入。
- 第一次登入時，姓名和 Email 會自動帶進「檢舉人資料」。
- 右上角頭像可以看帳號資訊和登出。
- 「忘記密碼」為模擬，不會真的寄信。
- **每個帳號的資料分開**：草稿、分析紀錄、案件、檢舉人資料都會記下是哪個帳號建立的，只有本人看得到；
  沒登入呼叫 API 會回 401，別人的影片、截圖網址也打不開（`core/store.py` 的 `owns()`）。
- 加上帳號隔離之前留下的舊資料（沒有記錄帳號），會歸給**最早註冊的帳號**。
- 檢舉人資料每個帳號一份，存在 `ui/data/profiles/`。舊的共用檔只給最早註冊的帳號當預設值。

## 自動儲存進度

每一次檢舉流程都是一份「草稿」，存在 `ui/data/drafts/`。上傳影片後就會自動建立，之後每一步都會自動存檔，畫面上方會顯示最後儲存的時間：

- 上傳的影片、GPS 設定、錄影時間
- AI 分析的進度與結果（分析中重新整理也會接著顯示進度）
- 違規審查時忽略了哪幾筆、目前的篩選
- 檢舉單裡改過的每個欄位
- 每筆違規產生的案件和送出狀態（同一筆違規重複編輯不會產生重複案件）

重新整理或關掉瀏覽器再打開，會回到上次停下的那一步。伺服器關掉再開也一樣。如果分析進行到一半伺服器被關掉，那次分析會標成「中斷」，按「重新分析」就可以。

要做下一支影片，按上方的「開始新的檢舉」。未完成的檢舉都列在「案件紀錄 → 進行中的檢舉」，可以繼續或刪除；刪除草稿不會刪掉已產生的案件。

## 和其他模組的對接

**autoForm（自動填表）**：每個案件會輸出成 `ui/data/cases/<案件>/`，內容是 `info.txt` 加 `evidence.mp4` 加 `evidence.jpg`，格式和 autoForm 讀的案件資料夾一樣。
第 5 步按「開啟瀏覽器自動填表」時，`core/store.py` 的 `start_autofill()` 把案件資料夾和檢舉人資料打包成 zip，
傳給推論服務的 `/reports`（說明見 `../inference_service/README.md`）。也可以手動執行：

```powershell
cd reporting\autoForm
python main.py --city kaohsiung --case-dir "..\..\ui\data\cases\<案件資料夾>"
```

注意：`違規事實` 的文字要和各縣市網站下拉選單的選項對得上，這部分要依 autoForm 各縣市 driver 調整。
推論服務搬上雲端後，填表仍要在自己的電腦跑：在 `config.json` 加 `"autoform_url": "http://127.0.0.1:8770"`。

**真實模型（traffic_ai）**：`core/remote.py` 的 `RemoteAnalyzer` 呼叫推論服務的 API，
再把組員的違規事件轉成 UI 的格式。對照方式：

| 組員輸出 | UI 顯示 |
|---|---|
| `rule_id`：`red_light_stop_line_crossing` 等 5 種規則 | 違規類型、檢舉單的違規類別／事實（對照表在 `core/analyzers.py` 的 `VIOLATION_TYPES`） |
| `status`：`confirmed` / `suspected` | 確定違規／疑似違規 |
| `conditions`（每個條件 true/false） | 「判定條件 x/y」與判定依據清單（中文說明在 `core/remote.py`） |
| `evidence.vehicle.plate_text`、`text_confidence` | 車牌與車牌信心；沒有車牌會提示在檢舉單補上 |
| `vehicle_class` | 檢舉單的車種（汽車／機車） |
| 違規片段 `*_violation_clips/run_*/` | 佐證影片（推論服務轉成 H.264）與截圖 |

新增規則時，只要在 `VIOLATION_TYPES` 和 `remote.py` 的 `RULE_TYPES` 各加一筆即可。

## 檔案結構

```text
ui/
├── server.py            # Web 伺服器與 API（只用標準函式庫）
├── core/
│   ├── analyzers.py     # 分析器介面、違規類型表、模擬分析器
│   ├── remote.py        # 真實模型：呼叫推論服務並轉換結果
│   ├── auth.py          # 登入／註冊（本機帳號、Google 模擬）
│   ├── store.py         # 上傳、分析工作、草稿、案件、檢舉人資料
│   ├── geo.py           # GPS → 縣市／行政區（離線查表）
│   └── gps_parser.py    # CSV / GPX / NMEA 軌跡解析
├── web/                 # 前端（index.html / app.js / style.css）
├── samples/             # 範例 GPS 軌跡
├── config.example.json  # 推論服務網址設定範例（複製成 config.json 使用）
├── data/                # 執行時產生的資料（已 gitignore）
├── 啟動介面.cmd
└── 手機展示模式.cmd
```
