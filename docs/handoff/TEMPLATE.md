# 功能／整合交接範本

複製本檔至 `docs/handoff/<功能名>.md` 或 PR 描述後填寫。無法驗證的欄位寫「未執行／原因」，不要填推測值。
角色工作約定見 [AGENTS.md](../../AGENTS.md)、[Astra](../ASTRA.md)、[Opus](../../CLAUDE.md)。

- 負責角色與交接對象：
- 狀態：開發中／待驗證／待整合／整合完成
- 基準 commit、工作分支／worktree：
- 交付 commit 或差異檔位置；未提交修改清單：
- 他人既有修改及如何避開：

## 4. 可重現環境

- 系統、Python、套件版本及各模型實際 provider／device：

- 基準 JSONL、遮罩、ground truth 的版本／識別；reviewed 範圍：
- 輸出獨立目錄（不得覆蓋對照組）：

## 5. 驗證與結果

- 本次測試命令、通過／失敗數、未執行項目與原因：
- 對照組與實驗組是否使用相同影片集合、模型與參數：
- 行為不變部分的等價比較；排除欄位及理由：
- 真實資料驗證方式：規則重算／完整後處理重播／模型重跑／完整辨識

| 指標 | 對照組 | 實驗組 | 分母／資料範圍／限制 |
| --- | --- | --- | --- |
| 事件 TP／FP／FN（按規則） | 待填 | 待填 | 僅 reviewed 影片 |
| 影片命中 | 待填 | 待填 | 不等於事件準確率 |
| 車牌正確數／可評估數 | 待填 | 待填 | 待填 |
| FPS、各階段 ms／幀 | 待填 | 待填 | 裝置、暖機、量測範圍 |

- 逐片變動事件：影片、秒數、車輛／車牌、原狀態 → 新狀態、證據連結、視覺核對結果。
- 新增誤報／漏報與反例：
- 歷史數據（若引用）來源與日期，和本次結果分開列：

- 未解決問題、下一步負責方：
