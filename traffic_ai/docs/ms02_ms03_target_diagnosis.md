# 使用者指定目標：ms03 / 000001、ms02 / 000002

此處以使用者補充的車號與約 3～4 秒時段為準，不使用先前 ms04 的推論。

## ms03：vehicle-000001

保存的模型輸出將該 ID 分類為 person；它的 track_age_frames 連續增加。
規則只接受 car、motorcycle、bus、truck，所以此目標在越線幾何判斷之前
就被排除，與號誌是否辨識成功無關。
第 95 幀標記影像可見該人物框與兩輪車框重疊，不能以人物框底邊
代替輪胎接地位置，也不能直接把 person 全部加入車輛允許清單。
先前分析的 motorcycle 66／112 是相關空間範圍內的另一組偵測 ID，
不是使用者指定的 ID；目前沒有騎士與車輛身份關聯功能。

## ms02：vehicle-000002

該目標分類為 car，追蹤年齡合格。第 80 幀（3.20 秒），
車框 x=542.4～756.93，底邊 y=847.19；可用停止線片段
x=1159～1254、y 約 998～1000，橫向不重疊。
第 90 幀（3.60 秒）也有同樣問題，因此沒有進入車線配對。
標記影像顯示車輛位於近處停止線前方，但單看此時的位置，
無法補出何時越線及越線當時的燈號。
本案例需要確認該車適用的停止線／車道及跨線前後軌跡；
直接將畫面右側片段無限延伸可能誤配不同車道。
